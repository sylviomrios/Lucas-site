# Lucas Gonçalves — Landing Page

Site one-page em Next.js, com narrativa por rolagem e direção artística esportiva premium. A primeira versão usa placeholders para os vídeos e fotografias reais.

## Rodar localmente

```bash
npm install
npm run dev
```

## Estrutura

Abertura cinematográfica (placeholder), frases/fotografias, agendamento, vídeos, apresentação do professor, modalidades e contato.
